# V1.4 contract bridge
All operations are design proposals. Existing live endpoint compatibility is authoritative. For each OPERATIONS item use schema_refs request/response in PAYLOAD-SCHEMAS.json. Draft 2020-12 schemas describe business payload; root catalog stores definitions (validation uses selected definition). Objects closed, identifiers opaque existing IDs, integer minor currency units with enterprise currency; quantity positive for debit, delta signed; UTC timestamps Z. Schema format date/date-time validation enabled by implementer. Authentication and business authorization cannot be enforced by schema alone. Scope P public rate limited, U self, V visit, T authorized staff, Q scoped HQ, S authenticated internal, X raw signed webhook adapter. Actor/tenant/store/merchant never derived from untrusted body. No arbitrary operation invocation endpoint.
Response business envelope status OK/REJECTED/PENDING/UNKNOWN with code, correlation_id, data only as appropriate. Request idempotency key for W; unique tenant+operation+actor+key, hash normalized payload, conflicting payload reject. Read operations may audit; durable quote/query intents marked W. A policy parameters reference is immutable versioned typed domain payload with verified hash; no general script evaluation. Adapter launch_ref resolves only scoped channel-specific client launch parameters through existing secure flow, not a new public generic resolver. Actual protocol fields verified per provider before use. A config.stage references candidate binding record, secrets always separate.
Transaction model: commit intent with DISPATCHING before outbound request; after crash status may be unknown. Recover by original reference. Provider-specific NOT_FOUND is not sufficient until documented safe terminal semantics. Allocation/hold/withdrawal remains reserved while UNKNOWN. Confirm terminal fact before release/new attempt. Inbound event dedup by tenant+event_id and payload hash, outbox in same authoritative transaction; durable retry and manual exception. No distributed write transactions invented.
