# BSV ALL 接入交付物

1. 在仓库外解包，检查路径穿越、CRC、来源许可、SHA-256、密钥和个人数据。将包和各文件的 SHA、版本及归档映射写入 `ingestion/sources/`；同批记录保持不可覆盖，后续修订另记来源。原件与受限数据继续保存在授权位置。
2. 对照 `config/`、`contracts/` 和现有行业务域。只在固定一级目录下集成，来源冲突先登记证据；稳定 ID 不因来源或界面改变。资料与批次规则沿用 [原始资料导入契约](../../contracts/IMPORT_PROTOCOL.md)，权威关系经来源审核后走现有预检。
3. 在独立分支接入安全源码，用临时存储和合成数据复跑原测试及跨模块测试。将可复现构建、受限预览、回退方案与未核验项写入状态文档，通过 CI 提交 PR。
4. 生产变更、支付、正式迁移和云端部署依据专项授权与实测恢复证据。旧程序与数据库保留，批准前只做隔离演练。
