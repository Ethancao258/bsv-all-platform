# ADR-0002｜中央数据库物理落点尚未最终裁决

状态：PENDING LIVE AUDIT。

现有报告：CloudBase PostgreSQL 上海已有产品库十表；组织母版 V5 提出今后在完成核验后逐步向 Lighthouse 统一承载共享业务数据/受控API。二者是物理部署方案差异，不能未经测量强行合并。

本阶段保留现有CloudBase PG为唯一报告中的主数据位置、不新建影子业务库；只搭建通用SQL契约与代码目录。Lighthouse API放置由后续网络/运维/合规验收确定。比较迁移前后备份RPO/RTO、成本、数据恢复、跨区延迟、监控、运维能力后再由用户批准。迁移必须在某一时刻只允许一个权威写入端，不允许无期限双主。
