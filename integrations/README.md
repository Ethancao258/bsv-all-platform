# 外部系统适配器（不是业务主数据）

- `payment/`：收钱吧或其他合规支付机构的API；签名验真、订单对账。
- `marketplaces/`：美团/抖音/团购和未来渠道引流、核销；按官方许可与平台能力。
- `messaging/`：企业微信/通知服务，仅承接经同意与授权的业务通知。
- `devices/`：HPRT T260L标签/门店设备/打印，与产品统一图形和SKU编码契约。
- `ai/`：Codex、ChatGPT、WorkBuddy 交接，读取相同Git规范，不自动赋予生产数据库权限。

**禁止**将外部平台返回的订单ID当成内部 `order_id`；建立对应映射和来源验证。
