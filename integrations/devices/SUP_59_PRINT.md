# SUP-59 标签与 A4 打印

总部和门店通过供货页面打开由 D 快照生成的打印文件。二维码使用原始包装 ID，可交给现有扫码功能，扫码结果还须由正常签收权限及事务确认。打印内容不经过外部二维码服务。

## HPRT T260L 单件、批量和补印

1. 在实际操作终端通过已安装的 HPRT 驱动选择 T260L。需要安装时从[汉印官方驱动中心](https://www.hprt.com.cn/XiaZai/)按机身铭牌和操作系统确认驱动。装入 50 × 40 mm 标签，按设备操作校准进纸。先在隔离环境打开合成标签，浏览器选择实际大小 100%、无页眉页脚、每页一张，关闭自动适合纸张。供应程序无需获得服务器 USB、打印命令或设备地址。
2. 先打单件，核对产品、实际装量、制作时间、死期、批次、制作人员、储存和包装 ID 均完整可见。扫码应精确返回同一包装 ID；使用手机及现场扫码器核对贴在实际瓶身后的可读性。
3. 再打两件批量任务，确认一件一张，无空白标签。复打同一件，核对原包装 ID、制作时间与死期。追溯码更换、缺页、误裁切、读码不一致或记录未知均视为验收未通过。
4. 浏览器只把页面交给系统打印对话框。能打开预览或浏览器关闭对话框不能证明设备出纸。打印历史应分别记生成/请求和经操作员确认的实物结果；卡纸、预览取消和作业未知不可记录为已出纸。

### 版式与回退

打印文件采用 50 × 40 mm CSS 页面及本地生成的 PNG 二维码。二维码为由既有扫描器识别的 1 至 64 个 ASCII 字符包装 ID（允许字母、数字、`_.:-`）。字段超出版式会拒绝生成，先检查批准的标签字段，可保持含义不变地换用批准的短名或另行审批版式；勿裁掉储存或效期。正式经营/许可要求的其他字段须由实际项目验收核对。

设备不可用时可先打印至 PDF 核对尺寸和内容，保留生成证据供后续重试。纸质标签未正式验收前，以现有批准流程完成所需标签与人工复核，不用预览代替出品放行。

## 到货清单及死期清单

选择 A4 纵向、黑白、实际大小。到货清单核对计划件数、实收、隔离和未确认数量、发收货和签字。死期清单需列出历史剩余和新到货，按是否可用及日期分组，同组按死期时间排序，保留版本及处置确认区。使用多页样本检查标题重复、行不截断及签字区可写。纸面确认不自动写库存处置或考勤。
